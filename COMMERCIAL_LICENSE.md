# Commercial Licensing

This repository is publicly available for inspection, verification, reproducibility testing, and non-commercial use.

**Public availability does not grant commercial usage rights.**

Public availability does not grant rights to deploy, host, operate, resell, or embed the Software commercially. Use of the "Market Lens" name or branding for commercial offerings also requires explicit written permission.

---

## What Is Allowed Without Permission

- Viewing, reading, and studying the source code
- Running the software for personal, educational, or research purposes
- Verifying results and reproducing outputs for validation
- Auditing the code for security or correctness
- Using the software for non-commercial prototypes
- Academic use in research and teaching
- Contributing improvements back to the project

---

## What Requires Written Permission

- Using the software in paid products or services
- Offering the software as part of a SaaS platform
- Integrating the software into commercial business systems
- Including the software in consulting deliverables for paying clients
- Reselling, white-labeling, or monetizing the software
- Any use intended for commercial advantage or monetary gain
